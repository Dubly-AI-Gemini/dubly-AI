# 🎙️ Dubly AI

### Real-Time AI Dubbing & Live Translation for Videos, Live Streams & Games

**Dubly AI** is a Chrome extension for **real-time AI voice dubbing and live translation** of online videos, live streams, streaming content, and gameplay.

Powered by **Google Gemini**, Dubly AI translates spoken content in real time and generates AI-dubbed audio in your preferred language.

Whether you are watching a **YouTube video, live stream, online video, gaming stream, or gameplay**, Dubly AI helps you understand content in your own language.

## 📦 Installation

### 1. Download Dubly AI

Go to the **[Releases](https://github.com/Dubly-AI-Gemini/dubly-AI/releases)** page and download the latest `.ZIP` file.

### 2. Extract the ZIP

Extract the downloaded ZIP file to a folder on your computer.

### 3. Open Chrome Extensions

Open:

```text
chrome://extensions
```

### 4. Enable Developer Mode

Turn on **Developer mode** in the top-right corner.

### 5. Load the Extension

Click:

**Load unpacked**

Then select the folder where you extracted Dubly AI.

### 6. Enter Your Gemini API Key

Open the Dubly AI extension, enter your **Google Gemini API key**, and click:

**Start dubbing**

## 🔑 Gemini API Key

Dubly AI uses **Google Gemini** for AI-powered speech translation and dubbing.

You can obtain a Gemini API key through **Google AI Studio**.

> Your API key is stored locally in Chrome and is sent only to Google for Gemini API requests.

For continuous and frequent use, a **paid Gemini API key** is recommended because free-tier usage may have rate limits.

---

## 🎧 How It Works

```text
        Online Video / Live Stream / Game
                       │
                       ▼
                 Original Speech
                       │
                       ▼
                Google Gemini AI
                       │
              ┌────────┴────────┐
              ▼                 ▼
         Translation          AI Voice
              │                 │
              └────────┬────────┘
                       ▼
                  Dubbed Audio
                       │
                       ▼
              Translated Content
```

Dubly AI captures spoken content from supported online media, processes the speech through Google Gemini, translates it into the selected language, generates AI voice output, and plays the dubbed audio while providing translated subtitles when available.

## ⚡ Translation Modes

### Gemini Live Translate

Provides continuous speech-to-speech translation for a more natural live dubbing experience.

### Fallback Translation Engine

If continuous live translation is unavailable or encounters limitations, Dubly AI can use segmented translation together with a voice engine as a fallback.
